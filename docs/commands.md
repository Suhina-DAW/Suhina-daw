# Commands

Every command Suhina has, generated from the command registry in `crates/session` by
`suhina-cli commands --markdown`; do not edit by hand. A workflow regenerates it on `main`
after every merge, so pull requests leave it alone. The CLI, the MCP server and the UI run
these same commands ([ADR 0002](decisions/0002-commands.md), [`mcp.md`](mcp.md)).

| Command | Kind | What it does | Parameters |
|---|---|---|---|
| `projects.list` | projects | List the open projects in tab order with id, name, source and whether each is active | none |
| `projects.switch` | projects | Make an open project the active one; the previous one stops playing | `project` (integer): project id, from projects.list |
| `projects.next` | projects | Make the next open project active, wrapping around after the last | none |
| `projects.previous` | projects | Make the previous open project active, wrapping around before the first | none |
| `projects.close` | projects | Close an open project and its undo history; a neighbour becomes active if it was | `project` (integer): project id, from projects.list |
| `plugins.list` | plugins | List the plug-ins the last scan found (id, name, vendor, version, features, file) and the files that failed | none |
| `plugins.scan` | plugins | Look for installed plug-ins in the standard folders and the added ones; reads only new and changed files unless all is true | `all` (bool, optional): read every file again, failed ones too (default false) |
| `plugins.folders` | plugins | List the folders a scan looks in: the system's standard ones and the ones added | none |
| `plugins.addFolder` | plugins | Add a folder for scans to look in, besides the standard ones | `folder` (text): a folder that holds plug-ins |
| `plugins.removeFolder` | plugins | Stop looking in a folder that was added | `folder` (text): a folder that holds plug-ins |
| `plugins.setHosting` | plugins | Choose how a plug-in's instances share host processes from their next start: binary (one process per plug-in file, the default), vendor (one per vendor) or instance (a process of its own for each) | `plugin` (text): plug-in name, id or file, from plugins.list; `hosting` (text): binary, vendor or instance |
| `plugins.check` | plugins | List a project's plug-in devices and the installed plug-in found for each: how it was found (same, declared, vst2-id, same-name, newer-version) and whether its saved settings are promised to carry over | `project` (integer, optional): project id, from projects.list (default the active one) |
| `library.folders` | library | List the browser's folders with how each is kept up to date (watching, polling, scanning, missing, idle) and how many files it holds | none |
| `library.addFolder` | library | Add a folder to the browser and index the samples, MIDI files, presets and projects in it | `folder` (text): a folder, as library.folders lists them |
| `library.removeFolder` | library | Remove a folder from the browser (the files stay where they are) | `folder` (text): a folder, as library.folders lists them |
| `library.refresh` | library | Read a folder, or every folder, again | `folder` (text, optional): a folder (default: every folder) |
| `library.list` | library | List what is directly in a folder: sub-folders first, then samples, MIDI files, presets and projects | `folder` (text): any folder |
| `library.search` | library | Search the folders' files, the built-in devices and the installed plug-ins; every word must appear in an item's name or path, best matches first | `text` (text, optional): the words to find (default: everything); `category` (text, optional): all (default), samples, midi, instruments, effects, presets or plugins; `place` (text, optional): pinned, recent:<group> (projects, samples, midi, instruments, effects, plugins, presets), or a folder; `tags` (texts, optional): only items carrying any of these tags; `limit` (integer, optional): at most this many (default and most 500) |
| `library.info` | library | What an item is: a sample's length, rate, channels, tempo (and whether it was detected) and key; a MIDI file's tracks; a preset bank's voices; a device's or plug-in's role | `item` (text): an item: a file's path, <bank>.syx#<voice>, device:<id> or plugin:<spec>, as library.search gives them |
| `library.pinned` | library | List the pinned items, oldest first | none |
| `library.pin` | library | Pin an item, so it is listed under Pinned | `item` (text): an item: a file's path, <bank>.syx#<voice>, device:<id> or plugin:<spec>, as library.search gives them |
| `library.unpin` | library | Unpin an item | `item` (text): an item: a file's path, <bank>.syx#<voice>, device:<id> or plugin:<spec>, as library.search gives them |
| `library.recent` | library | List the items used lately, newest first, by group (projects, samples, midi, instruments, effects, plugins, presets) | `group` (text, optional): one group (default: every group) |
| `library.tags` | library | List the colour tags (name, colour), the items carrying them and the most tags there may be | none |
| `library.setTag` | library | Add a colour tag, or change a tag's colour or name; or change the most tags there may be | `name` (text, optional): the tag; `color` (text, optional): its colour, #RRGGBB (needed for a new tag); `rename` (text, optional): a new name for it; `limit` (integer, optional): the most tags there may be, from 1 to 1024 (default 64) |
| `library.removeTag` | library | Remove a colour tag from the list and from every item | `name` (text): the tag |
| `library.tag` | library | Set or clear a colour tag on an item | `item` (text): an item: a file's path, <bank>.syx#<voice>, device:<id> or plugin:<spec>, as library.search gives them; `tag` (text): the tag's name; `on` (bool): true sets it, false clears it |
| `library.findFiles` | library | Find files by name (without regard to case), best first: in the browser's folders and the active project's folder, or by walking a folder; for missing files | `names` (texts): file names, such as kick.wav; at most 4096; `folder` (text, optional): walk this folder instead (depth 32, at most 1 000 000 entries) |
| `soundmap.status` | library | How far the sample map's analysis of the browser's samples is, per folder: analysed, queued, failed | none |
| `soundmap.analyse` | library | Analyse a folder's samples, or every folder's, again for the sample map, ignoring what was kept | `folder` (text, optional): a folder, as library.folders lists them (default: every folder) |
| `soundmap.layout` | library | Lay out samples by how they sound: each analysed sample's position (0–1), kind (kick, snare, hat…, and whether it was guessed) and whether it matches the text and tags; and how many are not analysed yet, too long or unreadable | `place` (text, optional): pinned, recent:samples, or a folder (default: every folder); `text` (text, optional): words a matching sample's name or path holds; `tags` (texts, optional): a matching sample carries any of these tags; `grid` (bool, optional): also give each sample's cell in a grid (column, row); `maxSeconds` (number, optional): leave out samples longer than this, 1 to 60 (default 10) |
| `soundmap.similar` | library | The samples that sound most like a sample, nearest first, with their distance | `item` (text): a sample's path; `count` (integer, optional): how many, 1 to 100 (default 16); `place` (text, optional): pinned, recent:samples, or a folder (default: every folder) |
| `soundmap.info` | library | What the sample map knows of a sample: its kind and where it comes from (its name or a guess), its length and its features | `item` (text): a sample's path |
| `audio.devices` | audio | List the audio hosts (WASAPI, ASIO, ALSA…) and each one's output devices with their sample rates and buffer sizes, and the output chosen | none |
| `audio.setOutput` | audio | Choose the audio output: host, device, sample rate, buffer size (the engine renders in blocks of it) and WASAPI exclusive mode; parts left out stay, an empty text or 0 goes back to the default. Reopens the active project's output, keeping the transport where it is | `host` (text, optional): a host from audio.devices, "" for the default; `device` (text, optional): an output device of that host, "" for its default; `sample_rate` (integer, optional): Hz, one the device lists; 0 for its default; `buffer_frames` (integer, optional): frames per buffer, 64 to 4096; 0 for the default; `exclusive` (bool, optional): WASAPI: open the device for Suhina alone (default false) |
| `audio.info` | audio | Say what the active project plays on now: host, device, sample rate, buffer frames, the engine's block, measured latency and underruns | none |
| `commands.list` | read | List every command with its parameters | none |
| `project.save` | read | Save the project as a Suhina project (.locr) with its plug-ins' state as it is now; without a path, to the .locr file it was opened from or last saved to | `path` (text, optional): file to save to; .locr is added when missing; `copy` (bool, optional): true writes a copy (a template, a backup) and the project stays with its own file |
| `project.info` | read | Summarise the open project: tempo, time signature, counts of tracks, scenes and clips, undo state | none |
| `project.tracks` | read | List tracks with id, name, volume (dB), pan, mute and devices | none |
| `project.clips` | read | List arrangement clips with track, index, start and length in beats, and note count | `track` (track, optional): only clips on this track (id or name) |
| `transport.setTempo` | edit | Set the project tempo | `bpm` (number): beats per minute, 20 to 999 |
| `track.setVolume` | edit | Set a track's volume | `track` (track): track id or name, from project.tracks; `db` (decibels): level in dB, at most +6; "-inf" or below -150 is silence |
| `track.setPan` | edit | Set a track's pan | `track` (track): track id or name, from project.tracks; `pan` (number): -1 is full left, 0 centre, 1 full right |
| `track.setMute` | edit | Mute or unmute a track | `track` (track): track id or name, from project.tracks; `mute` (bool): true mutes the track |
| `track.group` | edit | Put tracks into a new group track, which plays into where they played | `tracks` (tracks): the tracks to group (ids or names), all in the same group or none; `name` (text, optional): the group's name ("Group" if left out) |
| `track.ungroup` | edit | Dissolve a group track: its tracks stay, playing into where the group played | `track` (track): track id or name, from project.tracks |
| `track.move` | edit | Move a track (a group with its tracks) to another place in the track order | `track` (track): track id or name, from project.tracks; `to` (integer): its new position, from 0, in project.tracks order |
| `track.rename` | edit | Rename a track | `track` (track): track id or name, from project.tracks; `name` (text): the new name, not empty |
| `track.setColor` | edit | Set a track's colour | `track` (track): track id or name, from project.tracks; `color` (text): "#rrggbb", or "none" for the default |
| `track.delete` | edit | Delete a track with its clips; a deleted group's tracks stay | `track` (track): track id or name, from project.tracks |
| `clip.delete` | edit | Delete an arrangement clip | `track` (track): track id or name, from project.tracks; `index` (integer): clip index on the track, from project.clips |
| `clip.setGain` | edit | Set an audio clip's gain (every clip that plays the same audio content follows) | `track` (track): track id or name, from project.tracks; `index` (integer): clip index on the track, from project.clips; `db` (decibels): gain in dB, at most +24; "-inf" or below -150 is silence |
| `clip.setFades` | edit | Set an audio clip's fade-in and fade-out lengths, in beats; together at most the clip's length | `track` (track): track id or name, from project.tracks; `index` (integer): clip index on the track, from project.clips; `in` (number, optional): fade-in length in beats from the clip's start, at least 0; 0 is none; `out` (number, optional): fade-out length in beats before the clip's end, at least 0; 0 is none |
| `clip.copy` | read | Copy an arrangement clip, with what it plays, for clip.paste | `track` (track): track id or name, from project.tracks; `index` (integer): clip index on the track, from project.clips |

| `clip.duplicate` | edit | Place a copy of an arrangement clip right after it, replacing what the copy covers | `track` (track): track id or name, from project.tracks; `index` (integer): clip index on the track, from project.clips |
| `track.setOutput` | edit | Route a track's audio to the main output or into a group track | `track` (track): track id or name, from project.tracks; `to` (track): "main", or a group track (id or name) to play into |
| `track.setSolo` | edit | Solo a track or end its solo: while any track is soloed, only soloed tracks, the groups they play into and return tracks are heard | `track` (track): track id or name, from project.tracks; `solo` (bool): true solos the track; `exclusive` (bool, optional): true also ends every other solo (false by default) |
| `clip.move` | edit | Move an arrangement clip to a new start position, and to another track if asked; it replaces what it covers unless stacked | `track` (track): track id or name, from project.tracks; `index` (integer): clip index on the track, from project.clips; `start` (number): new start in beats from the beginning, at least 0; `to_track` (track, optional): track to move the clip to (id or name); it must take the clip's kind: notes or audio; `stack` (bool, optional): true leaves clips under it as they are (they all play); false (default) shortens, splits or removes them |
| `project.launcher` | read | List the clip launcher: scenes (name, tempo) and each track's slots (clip name, stop button) | none |
| `launcher.state` | transport | What the audio engine is playing: transport, tempo, position, each track's playing and queued clip, and the engine's CPU load | none |
| `transport.play` | transport | Start the transport from the play start marker (beat 0 unless moved): the arrangement plays, launches follow the beat | none |
| `transport.stop` | transport | Stop the transport, the arrangement and every launched clip at once; stopping while stopped moves the play start marker to beat 0 | `return` (text, optional): marker (default): the playhead goes back to the play start marker; here: the marker moves to where the playhead stopped |
| `transport.setPosition` | transport | Move the play start marker, where the transport starts; while playing, playback jumps there at once | `beats` (number): beats from the beginning, 0 … 120000 |
| `transport.setMetronome` | transport | Turn the metronome on or off: a click on every beat while playing, higher on the bar | `on` (bool): true turns the click on; `db` (decibels, optional): click level in dB, at most +6; keeps the current level (-6 at first) if left out |
| `clip.launch` | transport | Launch the clip in a track's slot at the next quantisation boundary (an empty slot with a stop button stops the track) | `track` (track): track id or name, from project.tracks; `scene` (integer): scene number, from 1, as in project.launcher |
| `scene.launch` | transport | Launch a scene: every track launches its slot in that row at the next quantisation boundary | `scene` (integer): scene number, from 1, as in project.launcher |
| `track.stop` | transport | Stop the clip a track is playing, at the next quantisation boundary | `track` (track): track id or name, from project.tracks |
| `launcher.stopAll` | transport | Stop every launched clip at the next quantisation boundary | none |
| `launcher.setQuantization` | transport | Set the grid launches wait for (default 1 bar) | `value` (text): none, 8 bars, 4 bars, 2 bars, 1 bar, 1/2, 1/2T, 1/4, 1/4T, 1/8, 1/8T, 1/16, 1/16T or 1/32 |

| `devices.list` | read | List the built-in devices (id, name, effect or instrument) with their parameters (id, range, default, unit, options) | none |

| `device.add` | edit | Add a built-in device to a track; an instrument goes first and plays the track's notes, an effect goes last unless a position is given | `track` (track): track id or name, from project.tracks; `id` (text, optional): built-in device id, from devices.list (not needed with a preset); `position` (integer, optional): where in the chain, from 0 (default: last; an instrument is always first); `preset` (text, optional): a preset file to load: DX7 voice data (.syx) for the FM synth; `voice` (integer, optional): which voice of a preset bank, from 1 (default 1) |
| `track.add` | edit | Add an audio or MIDI track with its mixer channel, clip slots and arrangement lane, optionally with a device (an instrument makes a MIDI track, an effect an audio track) | `kind` (text, optional): audio or midi (default: from the device); `name` (text, optional): the track's name (default: the device's, or Audio n / MIDI n); `after` (track, optional): put it after this track, in its group (default: after the last regular track); `device` (text, optional): a built-in device id from devices.list, or a plug-in from plugins.list; `preset` (text, optional): a preset file for the device (DX7 voice data for the FM synth); `voice` (integer, optional): which voice of a preset bank, from 1 |

| `preview.stop` | transport | Stop the preview | none |
